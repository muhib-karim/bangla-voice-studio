Bangla Voice Studio prepares Bangla text, runs local narration jobs, and exports audio and captions. Python CLI and a browser workspace, with no hosted inference.

ডেমো চালান Run the demo

Version 0.1.1. The built-in demo engine produces test tones; the real models are checked by a weekly smoke test.

নিজের কম্পিউটারে শুরু করুন Quick start

Python 3.11 or 3.12 and ffmpeg. Install from a checkout; installation does not download models.

git clone https://github.com/muhib-karim/bangla-voice-studio.git
cd bangla-voice-studio
python -m venv .venv
.venv/bin/python -m pip install .
.venv/bin/bvs normalize '৳৫০'
.venv/bin/bvs say 'আমি বাংলায় বলি।' --engine dummy --output demo.wav
.venv/bin/bvs serve --demo

Open http://127.0.0.1:8000. Speak, Clone, Transcribe, Audiobook, and Engines share a local job queue. Clone and Transcribe use simulated results in demo mode.
